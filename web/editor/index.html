Connexion GitHub

Pour enregistrer directement sur GitHub (le jeu se republie ensuite tout seul), colle un jeton d'accès personnel limité à ce dépôt. Il reste stocké uniquement dans ce navigateur — jamais envoyé ailleurs qu'à GitHub.

  1. Va sur github.com/settings/personal-access-tokens/new
  2. « Repository access » → Only select repositories → les-cryptes-eternelles
  3. « Permissions » → Repository permissions → Contents: Read and write (rien d'autre)
  4. Génère, copie le jeton (github_pat_…) et colle-le ci-dessous
